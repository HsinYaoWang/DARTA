# Explore a collaboration with DARTA

[English overview](../README.md) · [繁體中文首頁](../README.zh-TW.md) · [Demo walkthrough](walkthrough.md)

DARTA is building a way for biomedical data partners and model developers to agree on authorized use, connect models to their sources, and share qualifying revenue under clear terms.

Start with the problem you want to solve. A short, non-confidential description is enough for a first conversation.

| Your role | What we can explore together |
| --- | --- |
| **Data partner** — a laboratory, hospital, research group or other authorized contributor | Which uses you could authorize, how your contribution would be recorded, and how agreed training-use income and later model-use shares could work. |
| **Model developer or research team** | The data characteristics, authorized task, evaluation plan and permitted outputs needed for your model project. |
| **Team seeking commissioned development** | Whether a scoped DARTA-assisted project could help find suitable authorized data, run a standard training/evaluation task and deliver an evaluation report. This is an optional collaboration path. |

## Bring a use case, not a dataset

Tell us your role, the problem or intended use, the broad data type and approximate scale if relevant, and the outcome you want. A public description of your organization is optional. There is no need to share data or confidential details to begin.

**[Start a collaboration enquiry](https://github.com/HsinYaoWang/DARTA/issues/new?template=collaboration.yml)**

This opens a **public GitHub issue**. Please keep patient information, datasets, private contracts and credentials out of the issue and its attachments. GitHub replies provide the contact channel; you do not need to post an email address.

The next conversation is about fit and scope: what could be authorized, who would do the work, how success would be assessed, and which costs and deliverables would need agreement. An enquiry does not book a service or commit either party to a start date.

## Questions before we talk

**Can I sign up or upload data now?** The current demonstration runs locally with independently generated synthetic data, fictional participants and simulated USDC in an off-chain ledger. It is a way to discuss the workflow, not live onboarding or a clinical service. No real payment or patient-data processing is demonstrated.

**Will buyers receive the raw data?** Buyer raw-data download is outside the intended product scope. Authorized workflows would return permitted results; model delivery requires separate rights and output/security review. The current demo does not establish the privacy safety of real data or model outputs.

**Where would my data stay?** The intended approach prioritizes seller-controlled infrastructure or seller-controlled cloud. Those deployment options are not implemented in the local demo. Custody, access and execution arrangements would need to be agreed and verified for a real collaboration.

**How could data partners earn?** Two revenue types are illustrated: payment for authorized training-data use, and an agreed share of qualifying later model revenue. Each released model connects to specified source versions and frozen sharing terms. The demo recalculates simulated allocations; it does not pay real earnings. Revenue outside a DARTA-controlled payment path needs an authenticated integration or agreed reporting/audit evidence. A model record cannot observe every offline use.

**How would pricing work?** Participants agree data/model prices. The fee model being validated is **3% for the buyer and 3% for the seller**, each on the same pre-fee price, for training-data use and each completed, billable inference. A commissioned project would also have a startup service fee credited against that same project's buyer transaction fees, without reducing seller proceeds. The startup amount, service limits, refunds and sharing percentages require agreement; demo amounts and splits are illustrations, not a public tariff or earnings promise.

## 合作前常見問題

**現在可以註冊或上傳資料嗎？** 目前是本機展示版，使用獨立生成的合成資料、虛構參與者，以及記在鏈下帳本的模擬 USDC，供雙方討論流程。尚未開放正式進件，也不是臨床服務；未展示真實付款或患者資料處理。

**買方會取得原始資料嗎？** 目前產品方向不提供買方下載原始資料。授權流程應交付允許的結果；模型交付需另行確認權利並完成輸出／安全審查。現有 demo 不代表真實資料或模型輸出已通過隱私安全驗證。

**資料會放在哪裡？** 產品方向優先採用賣方控制的自有環境或雲端；本機 demo 尚未實作這些部署方式。正式合作的保管、存取與執行安排仍須約定並驗證。

**資料提供者如何獲得收入？** 展示兩種收入：授權訓練使用費，以及符合約定條件的後續模型收入分潤。模型版本連結特定資料版本及固定分配條款；demo 可重算模擬分配，但沒有支付真實收益。DARTA 收款流程以外的收入，需要可信的整合來源或約定的申報／查核；模型紀錄無法觀察所有離線使用。

**費用怎麼算？** 資料／模型價格由雙方約定。目前驗證的費用方向為訓練資料使用及每筆完成、可計費的推論，**買賣雙方各按同一筆未加費價格計收 3%**。委託案件另有啟動服務費，可折抵同案的買方交易費，不減少賣方實收。啟動金額、服務額度、退款與分潤比例須另行約定；展示金額及比例不是公開定價或收益承諾。
