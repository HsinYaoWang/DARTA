# DARTA

**讓資料成為有用的模型，讓貢獻者一起分享價值。**

DARTA 正在打造連結生醫資料授權、模型開發與收益共享的平台。讓需要資料的團隊能清楚約定用途、完成模型工作，也讓資料提供者依約參與模型創造的價值。

**[看 MRSA 資料評估案例](MRSA.md#繁體中文) · [看展示流程](docs/walkthrough.md#繁體中文) · [聊聊合作需求](docs/collaborate.md#繁體中文) · [English](README.md)**

> **目前可體驗：** 使用合成資料與模擬 USDC 的本地展示版。一起走過流程，討論它如何回應你的團隊需求。

## 我們希望幫助誰

| 你的角色 | DARTA 希望幫你做到的事 |
|---|---|
| **資料提供者** — 醫院、實驗室、研究團隊 | 清楚約定資料用途，追溯哪些模型使用了自己的貢獻，並核對依約分配的收益。 |
| **模型開發者** — 研究、診斷技術與生技團隊 | 約定資料使用權，完成模型訓練與評估，並事先說清楚如何分享符合條件的模型收入。 |
| **委託模型開發的團隊** | 從研究問題出發，討論合適且可授權的資料、標準訓練與評估報告，先確定工作範圍與交付內容。 |

合作從你的研究與業務需求開始，先用清楚的語言約定用途、權利、成果與費用。

## 先了解資料品質，再決定授權多少

DARTA 規劃先評估賣方資料的來源、完整性、可用數量與研究適用性，協助買方決定資料使用授權範圍，也讓賣方清楚呈現資料的優勢與限制。

**[MRSA 評估案例](MRSA.md#繁體中文)** 示範：假設 10,000 筆資料經審核後保留 8,000 筆，如何依類別涵蓋情況估算初步需求，再透過模型研究判斷是否擴大。數字皆為虛構示例，不是可購資料的實測結果，也不代表正式評估服務已上線。

## 資料貢獻者的兩種收益來源

**訓練資料使用收入。** 針對約定的模型工作，明確授權資料用途並約定價格。

**後續模型收入分潤。** 依約分享符合條件的模型收入，並連結到明確的模型版本與資料貢獻紀錄。

這是兩種不同的收入。價格、權利、分配方式及哪些收入納入分潤，都需要在專案中約定。

## 從研究問題，到共同分享價值

1. **說清楚目標。** 約定用途、工作範圍、交付內容與評估方式。
2. **評估資料並確認授權。** 先看品質與適用性，再約定可用範圍、權利與費用。
3. **訓練並評估模型。** 執行核准的標準任務，先看報告，再決定是否核准模型發布。
4. **連結每一份貢獻。** 記錄模型使用的資料版本，以及事先約定的分潤規則。
5. **使用並核對收益。** 按照已完成、經授權的模型使用計費，再依約分配收益。

產品方向是透過受控流程使用資料，不提供買方下載原始資料，並優先採用賣方控制的儲存環境。目前合成展示在本機執行；賣方端運算仍待實作。

## 看看流程如何運作

[展示導覽](docs/walkthrough.md) 以虛構的生醫研究專案，串起買方需求與賣方收益：

- 買方提出需求，並使用同一專案的啟動服務費折抵額。
- 兩位虛構資料提供者，授權合成資料用於標準訓練。
- 程式實際以合成紀錄訓練小型分類模型，並產生評估結果。
- 模型批次使用先預留資金，再結算完成項目、釋放未用額度。
- 每位資料提供者可核對自己的收益與計算過程。

展示也包含部分失敗與重送情境：失敗項目不收推論費，同一請求重送不會再次扣款。

## 目前提供的體驗

| 項目 | 目前狀態 |
|---|---|
| **可操作展示** | 來源審核、授權、合成訓練與評估、模型與來源紀錄、啟動費折抵、平台端批次帳務與貢獻者分配。 |
| **付款狀態** | 鏈下內部帳本中的模擬 USDC，尚未啟用真實付款。 |
| **部署狀態** | 本地展示。真實機構身分驗證、賣方控制的運算環境、支付整合與正式環境資安，仍待建置及驗證。 |

展示使用虛構參與者與合成資料，不代表真實客戶交易或臨床驗證。真實合作需先約定權利、隱私、資安與商業安排。
